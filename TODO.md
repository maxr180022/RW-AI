# TODO и точный статус функций (0.2.0)

Статусы: **DONE-TESTED** — реализовано и проверено автотестами на JVM · **IMPLEMENTED-UNVERIFIED** — код написан, не компилировался и не
запускался на устройстве · **NOT IMPLEMENTED** — нет в коде.

## Ядро
- DONE-TESTED: протокол ответа модели, валидация инструментов, матрица подтверждений, защита от prompt injection, цикл агента, лимиты, редактирование журнала
- IMPLEMENTED-UNVERIFIED: клиент DeepSeek (thinking, повторы, ошибки 401/402/429/5xx, учёт токенов, дневной лимит)
- IMPLEMENTED-UNVERIFIED: хранение ключа (Keystore AES-GCM), настройки, SQLite+FTS4 память, срок хранения, экспорт/очистка

## Управление Android
- IMPLEMENTED-UNVERIFIED: Accessibility (чтение дерева, поиск, нажатие, прокрутка, ввод текста, «Назад»), запуск приложений с проверкой, открытие ссылок
- IMPLEMENTED-UNVERIFIED: служба уведомлений (MessagingStyle, скрытые, маскирование кодов, исключения)
- IMPLEMENTED-UNVERIFIED: foreground-служба, уведомления подтверждения/«Стоп»/результата
- IMPLEMENTED-UNVERIFIED: голос (push-to-talk, TTS), экраны Compose (6 вкладок)
- NOT IMPLEMENTED: OCR и захват экрана (MediaProjection) — резервный путь, когда нет дерева элементов
- NOT IMPLEMENTED: нажатия по координатам (резервный вариант)
- NOT IMPLEMENTED: `open_notification`, `create_reminder`, long_press
- NOT IMPLEMENTED: отдельные инструменты календаря/контактов/файлов (доступны только через интерфейс приложений общим способом)

## Переписки (этап 4 ТЗ)
- NOT IMPLEMENTED: проверенные сценарии отдельно для Gmail / WhatsApp / Telegram / Instagram. Сейчас агент работает универсально
  (открыть → прочитать экран → прокрутить → нажать); надёжность на конкретных версиях приложений неизвестна.

## Память (этап 5)
- IMPLEMENTED-UNVERIFIED: поиск по словам с усечением русских окончаний, фильтр по приложению
- NOT IMPLEMENTED: поиск по смыслу (векторный), фильтр по датам/контактам в интерфейсе, извлечение договорённостей отдельной функцией
  (сейчас — через запрос к модели), хронология

- NOT IMPLEMENTED: раздел «Automation» (правила по контактам/приложениям, шаблоны типовых обращений), автоответ на входящие в фоне

## Оптимизация (этап 7)

- NOT DONE: Release APK (нужен ваш keystore), подписание; Android Lint

## Сборка и тесты
- NOT DONE (нужна среда с Android SDK): первая успешная Gradle-сборка, проверка версий библиотек
- NOT DONE: запуск инструментальных тестов, проверка на Samsung Galaxy

## Отклонения от ТЗ
- Вместо Room → SQLiteOpenHelper + FTS4; вместо DataStore → SharedPreferences; без kotlinx.serialization (собственный JSON) —
  чтобы сократить зависимости до первой проверки сборкой. Можно заменить позже без изменения логики.
