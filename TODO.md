запускался на устройстве · **NOT IMPLEMENTED** — нет в коде.

## На будущее (продажа, решение владельца 2026-11-08)
- Голос Дмитрий входит в установочный пакет приложения: покупатель скачивает его вместе с приложением и ничего не докачивает отдельно (для Google Play это отдельный пакет ресурсов, ставящийся вместе с приложением, около 64 МБ). Сейчас голос докачивается сам по Wi-Fi при первом запуске.
- Локальную модель (Gemma 4 E4B, 3,4 ГБ) покупатель по-прежнему скачивает отдельно и по желанию.
- Все голоса для основных языков (русский, English, Español, Deutsch) покупатель получает вместе с установкой, без докачки (решение владельца). Размер: около 64 МБ на голос, то есть 250–400 МБ пакетом ресурсов Google Play; решить, какие голоса класть по умолчанию (например, по одному на язык), остальные по желанию.
