# История изменений

## 0.5.2 — 2026-11-08
- Исправлено: при светлой системной теме телефона текст в чате был белым на светлом фоне (нечитаемо). Теперь приложение всегда тёмное, системные панели тоже.

## 0.5.1 — 2026-11-08
- Команды через «@»: @почта, @ютуб, @музыка, @календарь, @телефон, @интернет, @входящие, @телеграм, @ватсап, @инстаграм, @документ, @компьютер (у каждой есть синонимы). Подсказки появляются при наборе «@». Команда заранее указывает модели источник, поэтому она не ищет путь сама и тратит меньше токенов. Экран «Ещё → Команды @»: список и свои команды (имя + инструкция).
- Навигация: внизу три вкладки — Агент, Входящие, Ещё. «Ещё» — плитки: Память, Журнал, Телефон, Команды @, Подключения, Профиль, Параметры, Доступ. «Назад» возвращает в меню.
- «Подключения»: карточки в новом стиле, статус не ломает заголовок.
- Тесты: 143 JVM-теста.

## 0.5.0 — 2026-11-08
- Новый дизайн: тёмная «нейро»-тема с градиентом логотипа, мягкое свечение фона, компактная нижняя панель (52 dp, векторные иконки), стеклянные пузыри чата, поле ввода с круглыми кнопками, градиентная кнопка отправки.
- Документы: инструменты `make_pdf` (заявления, иски, письма: шапка справа, заголовок по центру, красная строка, поля 3/1,5/2/2 см, номера страниц), `draw_image` (схемы, плакаты, афиши из фигур), `annotate_document` (выделить/подчеркнуть/обвести/зачеркнуть фразу, текст, стрелки, рамки на PDF и картинках). Кнопки «Открыть / Поделиться / Скачать» в чате, копия в «Загрузки/Rusya AI». Данные владельца подставляются из профиля на телефоне и не уходят модели.
- Можно поделиться PDF или фото с приложением («Поделиться → Руся AI»), чтобы разметить их.
- Пробуждение: «Руся», «Окей, Руся», «Привет, Руся».
- Читаемость: текст на всех экранах светлый (раньше на тёмном фоне оставался чёрным); логотип с вырезанным фоном на стартовом экране и в шапке.
- «Входящие»: сводка разбита на цветные карточки (срочно, ждут ответа, договорённости, сообщения) без звёздочек; кнопки «Ответить» / «Открыть» / «Разобраться» / «В календарь» (подставляют команду в поле агента, ничего не отправляют сами). Жирный Markdown в чате отображается как жирный.
- Тесты: 137 JVM-тестов.

## 0.3.0 — 2026-11-08
- Приложение переименовано в «Руся AI». Создатели в ответах агента: Maxim Ricco (Максим Рикко) и RusWeo (РусВео).

## 0.2.0 — 2026-11-08
- Панель ассистента поверх экрана (как у Google) с логотипом и анимацией; команда уходит сама, ответ всегда озвучивается (и из шторки).
- Возврат в приложение, откуда позвали агента; без лишнего «домой».
- Имя RW Agent («Эр Вэ Агент»), создатель RusWeo, мужской род и мужской голос, если он есть на телефоне.

- «Окей, Руся»: офлайн-распознавание (Vosk), режимы работы; вкладка «Телефон» (батарея, температура, советы).

- Кнопка 📷: съёмка фото камерой прямо из чата с агентом.
- Журнал сбоев (CrashLog), исправлен вылет на вопросе «Как тебя зовут» (экранирование `{{`/`}}` в регулярном выражении).

- Тесты: 113 JVM-тестов логики + 5 тестов моста (Python).
