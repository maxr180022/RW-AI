# История изменений

## 0.2.0 — 2026-11-08
- Панель ассистента поверх экрана (как у Google) с логотипом и анимацией; команда уходит сама, ответ всегда озвучивается (и из шторки).
- Возврат в приложение, откуда позвали агента; без лишнего «домой».
- Имя RW Agent («Эр Вэ Агент»), создатель RusWeo, мужской род и мужской голос, если он есть на телефоне.
- Зашифрованный профиль владельца и подстановка в формы без показа значений модели.
- «Окей, Руся»: офлайн-распознавание (Vosk), режимы работы; вкладка «Телефон» (батарея, температура, советы).
- Интернет-поиск (`web_search`, `fetch_page`): DuckDuckGo, Wikipedia, ключ Brave по желанию; защита от утечки личных данных в запрос.
- Сводка «кому ответить» после долгого простоя экрана; фильтр рекламы/групп/кодов; автоперевод es/en → ru во «Входящих» (БД v2).
- Проверка приложений (признаки риска) и топ приложений по времени на экране; «не антивирус».
- Мост к Claude Code (`bridge/rw_bridge.py`, инструмент `ask_claude_code` с подтверждением).
- Кнопка 📷: съёмка фото камерой прямо из чата с агентом.
- Журнал сбоев (CrashLog), исправлен вылет на вопросе «Как тебя зовут» (экранирование `{{`/`}}` в регулярном выражении).
- Исправлено определение «служба включена / ассистент выбран».
- Тесты: 113 JVM-тестов логики + 5 тестов моста (Python).

## 0.1.0 — 2026-11-07
Первый рабочий этап (этапы 1–3 ТЗ в коде; этапы 4–7 частично, см. TODO.md).
- Ядро агента на чистом Kotlin с 67 JVM-тестами.
- Клиент DeepSeek (thinking), Keystore-хранилище ключа, настройки, SQLite+FTS4.
- Accessibility-исполнитель, служба уведомлений, foreground-служба, подтверждения.
- Голосовой ввод/вывод, интерфейс Jetpack Compose (Ассистент, Входящие, Память, Журнал, Доступ, Настройки).
- GitHub Actions: сборка debug/release APK, SHA-256, отчёты.
- Исправлено по ходу разработки: ложные срабатывания «юридических слов» (`договорились`, `рубашка`, `Европа`, `signal`);
  `\b` в Java не работает с кириллицей в JDK 19+ — заменён на Unicode-lookaround.
