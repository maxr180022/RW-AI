# Безопасность RW AI

## Модель угроз и меры

| Угроза | Мера | Где | Проверено |
|---|---|---|---|
| Prompt injection из писем/сообщений/сайтов/экрана | Весь внешний текст оборачивается в `<untrusted_data … id=NONCE>`; удаляются управляющие/невидимые символы и поддельные теги; обнаружение типовых фраз (RU/EN/ES) с предупреждением модели; системные правила: данные ≠ команды | `logic/Security.kt`, `AgentLoop` | Юнит-тесты (JVM) |
| Модель просит опасное действие | Закрытый каталог инструментов; валидация аргументов; политика по тексту фактически нажимаемого элемента; сверка найденного элемента с запросом | `Tools.kt`, `Policy.kt`, `LabelClassifier` | Юнит-тесты (JVM) |
| Отправка/оплата/удаление без ведома | Матрица подтверждений; показ получателя и полного текста; отказ = остановка задачи; тайм-аут = отказ | `Policy.kt`, `AgentController` | Юнит-тесты логики; UI-часть не проверена на устройстве |
| Подтверждение с заблокированного телефона | Кнопка в уведомлении требует разблокировки (Android 12+), на экране блокировки содержимое скрыто; опасные действия — только внутри приложения | `AgentService.kt` | Не проверено на устройстве |
| Утечка API-ключа | Шифрование AES-256-GCM, ключ в Android Keystore; нет в исходниках/APK; маскирование в журнале; запрет ввода/озвучивания ключа; агент не видит экран RW AI; поле ввода ключа — password | `SecretStore`, `Policy`, `SecretRedactor` | Юнит-тесты (маскирование/запрет); Keystore — инструментальный тест написан, не запускался |
| Вывод данных через ссылки | `open_url`: только http/https; длинные/параметрические ссылки — подтверждение | `Policy.kt` | Юнит-тесты |
| Обход защит Android | CAPTCHA/биометрия/PIN/код → `Deny`; при блокировке экрана инструменты отказывают; поля паролей не читаются, ввод запрещён | `Policy`, `RwAccessibilityService`, `AndroidToolExecutor` | Политика — тесты; остальное не проверено на устройстве |
| Зацикливание/расход токенов | Лимит 30 шагов, обнаружение повторов, дневной лимит токенов, бюджет контекста | `AgentLoop`, `DeepSeekClient` | Юнит-тесты (loop) |
| Перехват трафика | Только HTTPS (`network_security_config`), проверка Base URL | manifest, `Endpoint` | Юнит-тесты (Endpoint) |
| Утечка данных из резервных копий | `allowBackup=false`, правила извлечения исключают всё | manifest | Не проверено |
| Секреты в логах | `SecretRedactor` в журнале и ошибках API; содержимое переписки не логируется в logcat (в коде нет `Log.*`) | везде | Просмотр кода |

## Остаточные риски (важно знать)

1. **Прямой вызов API с телефона.** Ключ хранится зашифрованно, но на рутованном/скомпрометированном устройстве его можно
   извлечь. Для строгой защиты нужен собственный прокси-сервер (опция в ТЗ; не реализована).
2. **Prompt injection не решается полностью.** Меры снижают риск, но модель — вероятностная система. Поэтому критичные
   действия защищены не промптом, а программной политикой и подтверждением.
3. **Политика основана на тексте элементов** на RU/EN/ES. Кнопка без текста (только иконка) или на другом языке может не распознаться
   как «Отправить». Поэтому по умолчанию режим «Ассистент», а автоотправка выключена. Не включайте автоотправку, пока не проверили
   нужные приложения.
4. **Данные уходят в DeepSeek.** Всё, что агент прочитал для задачи (фрагменты экрана, уведомлений, переписки), отправляется в API
   DeepSeek. Исключайте чувствительные приложения. Политика конфиденциальности DeepSeek — на их сайте.
5. **Специальные возможности — мощный доступ.** Устанавливайте только собранный вами/вашим репозиторием APK и храните репозиторий закрытым.
6. Debug-APK подписан общим debug-ключом; для постоянного использования соберите release со своим ключом.
