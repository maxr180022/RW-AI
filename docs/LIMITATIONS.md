# Ограничения (0.1.0)

## Ограничения Android (не обходятся и не будут обходиться)

- Нельзя законно прочитать внутренние базы WhatsApp/Telegram/Instagram. Агент видит только то, что отдаёт интерфейс (Accessibility)
  и уведомления. «Полная история» = то, что агент прокрутил и прочитал на экране. Поиск по старым диалогам — через открытие
  приложения и просмотр истории, а не по скрытому индексу.
- Защищённые экраны (`FLAG_SECURE`), банковские приложения, поля паролей, CAPTCHA, биометрия, экран блокировки — недоступны.
- Android 10+ ограничивает запуск Activity из фона; запуск приложений может не сработать, если RW AI не на переднем плане.
  Агент проверяет результат запуска и сообщает о неудаче.
- Android 13+: для APK не из магазина Accessibility включается только после «Разрешить ограниченные настройки».
- Samsung One UI может усыплять приложения: нужна настройка батареи «Без ограничений». После force-stop, отзыва разрешений или
  выгрузки процесса система остановит работу — продолжение невозможно до ручного запуска.
- Обновления WhatsApp/Gmail/Telegram/Instagram меняют интерфейс; универсальный поиск элементов по тексту может перестать находить
  кнопки. Сценарии для каждого приложения не зашиты (см. TODO).

## Не реализовано / не проверено — см. TODO.md

нет правил автоответов по контактам; нет отдельных инструментов для календаря/контактов/файлов (только через интерфейс приложений);
нет восстановления прерванных задач после перезапуска процесса; нет собственного backend-прокси; код Android не скомпилирован
