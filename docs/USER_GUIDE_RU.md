# RW AI — руководство пользователя (версия 0.3.0)

## 1. Первая настройка (10 минут)

1. **API-ключ DeepSeek.** Вкладка **Настройки** → поле «API-ключ DeepSeek» → вставьте ключ → **Сохранить ключ**.
   Ключ шифруется на телефоне. Никому его не отправляйте и не вставляйте в чаты.
2. **Модель.** По умолчанию `deepseek-flash` с режимом рассуждения (thinking). Для сложных задач можно выбрать `deepseek-v4-pro`
   (дороже и медленнее). Название можно ввести вручную — оно должно совпадать с документацией DeepSeek.
3. Нажмите **Проверить соединение**. «Успешно» — ключ принят. Ошибка 401 — неверный ключ; 402 — нет средств на аккаунте.
4. Вкладка **Доступ** — включите по порядку:
   - **Доступ к уведомлениям** → откроются системные настройки → включите «RW AI — чтение уведомлений».
   - **Специальные возможности** → прочитайте пояснение → в системных настройках: *Установленные приложения / Загруженные
     службы* → **RW AI — управление интерфейсом** → включите.
     *Если переключатель серый и написано «Ограниченная настройка» (Android 13+):* Настройки → Приложения → RW AI → ⋮
     (три точки справа сверху) → **Разрешить ограниченные настройки**, затем вернитесь и включите службу.
   - **Микрофон** и **Показ уведомлений** — по кнопкам «Разрешить».
5. (Рекомендуется для Samsung) Настройки → Приложения → RW AI → Батарея → **Без ограничений**, иначе One UI может усыплять приложение.

## 2. Режимы автономности (Настройки)

| Режим | Что делает |
|---|---|
| Ассистент (по умолчанию) | Читает, ищет, делает сводки, готовит черновики. Любая отправка — после вашего «Подтвердить» |
| Оператор | Сам выполняет безопасные действия; обычные ответы — отправляет сам, если включена «Автоотправка» |
| Автономный | Решает многошаговые задачи сам. Оплата, удаление, смена безопасности — **всегда** с подтверждением |

Автоотправка не срабатывает, если в тексте есть деньги, договоры, юридические слова — тогда спрашивает вас.

## 3. Команды (вкладка «Ассистент»)

Текстом или кнопкой **Голос** (нажали → сказали команду). Начните с безопасных:

- «Открой Gmail»
- «Покажи последние доступные уведомления»
- «Прочитай последнее сообщение WhatsApp» (откроет WhatsApp и прочитает видимый текст)
- «Найди в памяти сообщения про аренду»
- «Сделай сводку открытой переписки»
- «Переведи последнее сообщение на русский»
- «Подготовь ответ на испанском, но пока не отправляй»
- «Покажи, что ты сделал сегодня» → вкладка **Журнал**

Во время задачи показываются шаги, кнопка **Стоп** есть в приложении и в постоянном уведомлении. Когда нужно подтверждение,
появится карточка с получателем и **полным текстом** (и уведомление). Отправка из уведомления требует разблокировки телефона;
оплата/удаление подтверждаются только внутри приложения.

## 4. Что агент НЕ сделает

- Не обойдёт PIN, отпечаток, CAPTCHA, экран блокировки, не введёт пароль/код из SMS. Если нужно — попросит вас сделать это самому.
- Не прочитает содержимое, которое приложение скрыло от системы (защищённые экраны, секретные уведомления). Он скажет об этом.
- Не будет следовать «инструкциям» из писем, сообщений и сайтов — это данные, а не команды.
- Не станет утверждать, что письмо отправлено, пока не проверит экран.

## 5. Приватность и удаление данных

- Все данные (уведомления, память, журнал) хранятся **только на телефоне**; резервное копирование выключено.
- В запросы к DeepSeek уходит: ваша команда и ровно те фрагменты экрана/уведомлений, которые агент прочитал для задачи.
  Если вы не хотите этого для какого-то приложения — добавьте его в «Исключённые приложения» или не давайте агенту его открывать.
- Вкладка **Память**: поиск, **Экспорт**, **Очистить**. **Настройки → Удалить все данные**; **Удалить ключ** убирает API-ключ.
- Коды из SMS/мессенджеров в уведомлениях маскируются (можно выключить).

## 6. Если что-то не работает

| Симптом | Что сделать |
|---|---|
| «Служба специальных возможностей не включена» | Вкладка «Доступ» → включить (см. п. 1.4) |
| Агент не открывает приложение | Android может блокировать запуск из фона; держите RW AI открытым при запуске задачи |
| «Входящие» пусты | Включите доступ к уведомлениям; отключите оптимизацию батареи для RW AI |
| Ошибка 401 / 402 / 429 | Неверный ключ / нет баланса / слишком частые запросы |
| Голос не распознаётся | Выдайте микрофон; в Samsung должен быть включён голосовой ввод Google/Samsung |
| Экран «пустой» для агента | Приложение защитило содержимое — это ограничение Android, не ошибка |

## 7. Вызов ассистента и голос

- **Кнопка/жест ассистента** открывает компактную панель с логотипом, а не всё приложение. Команда отправляется сама, ответ **всегда озвучивается**.
  Чтобы жест открывал RW AI: Настройки телефона → Приложения → Приложения по умолчанию → Цифровой помощник → RW AI.
- **Из шторки**: поле «Команда для RW AI…» — ответ тоже звучит голосом.
- **«Окей, Руся»** (вкладка **Телефон**): скачайте голосовую модель (≈45 МБ, один раз, по Wi‑Fi), включите переключатель, выберите режим
  (только на зарядке / зарядка или экран / всегда). Распознавание идёт офлайн. После перезагрузки телефона откройте приложение один раз.
- После задачи агент возвращает вас туда, откуда вы его позвали (если он уходил в другие приложения).
- Агента зовут **Руся AI**; создали его Maxim Ricco (Максим Рикко) и RusWeo (РусВео).

## 8. Профиль владельца (заполнение форм)

Вкладка **Настройки → Профиль**: имя, телефон, адрес, e‑mail и т. п. Данные шифруются на телефоне. Агент подставляет их в формы по меткам
`{{profile.ключ}}`; **значения модели не показываются**. Первый ввод в каждом приложении подтверждаете вы.

## 9. Интернет-поиск

Если нужного нет на телефоне, агент ищет в интернете (`web_search`) и читает страницы (`fetch_page`). Личные данные в запросы не попадают,
банковские сайты и локальная сеть закрыты. Без ключа — DuckDuckGo и Wikipedia; с ключом Brave Search (Настройки → Дополнительно) стабильнее.

## 10. Сводка сообщений и перевод

- **Сводка «кому ответить»**: после того как экран был выключен дольше N часов (по умолчанию 4) и вы разблокировали телефон, приходит уведомление:
  кто ждёт ответа и о чём. Реклама, рассылки, коды и шумные группы отфильтровываются (сколько отфильтровано — указано внизу). Вручную: **Входящие → Кто ждёт ответа**.
- **Автоперевод**: сообщения на испанском и английском переводятся на русский и показываются во «Входящих» под оригиналом.
  Ответ собеседнику агент готовит на его языке; перед отправкой вы видите текст.
- **Голосовые сообщения**: в уведомлении приходит только «🎤 Голосовое», без звука, поэтому RW AI их не расшифровывает. Включите в WhatsApp
  «Расшифровка голосовых сообщений» (Настройки → Чаты) — текст придёт в уведомлении и будет обработан.
- Для перевода и пересказа текст отправляется в DeepSeek. Отключается в Настройки → Дополнительно.

## 11. Вкладка «Телефон»: здоровье и безопасность

- Заряд, температура батареи, тепловое состояние, расход при выключенном экране, советы.
- **Проверка приложений**: приложения, установленные не из магазина, с доступом к чтению экрана, уведомлений, SMS, правами администратора.
  **Это не антивирус** (нет вирусных баз и проверки кода) — только признаки риска, которые стоит проверить глазами.
- **Что греет телефон**: нужен «Доступ к статистике использования» (системное разрешение). Тогда видно, какие приложения сегодня дольше всего были
  на экране. Точный расход заряда по приложениям Android сторонним программам не отдаёт.

## 12. Мост к Claude Code на компьютере (по желанию)

Нужен, только если хотите, чтобы агент передавал сложные задачи Claude Code на вашем компьютере (по вашей подписке). Каждый вызов вы подтверждаете.
Без моста всё остальное работает.

**Что нужно:** компьютер с установленным Claude Code (вы в нём вошли) и Python; телефон и компьютер в одной Wi‑Fi сети.

1. Скачайте папку `bridge` проекта на компьютер.
2. **Windows:** двойной щелчок по `start-bridge.bat`. **Mac/Linux:** в терминале `./start-bridge.sh`.
3. В открывшемся окне появятся **Адрес** и **Токен** (токен создаётся сам при первом запуске). Окно не закрывайте.
4. На телефоне: Руся AI → Ещё → Параметры → «Мост к Claude Code» → вставьте Адрес и Токен → **Сохранить**.
5. Проверка: скажите агенту «Спроси у Claude Code на компьютере, какая сегодня версия Python». Появится запрос подтверждения.

По умолчанию Claude Code работает в режиме «только чтение/планирование». Правки файлов включаются запуском с `--allow-edits`.
Не открывайте порт 8765 в интернет; вне дома используйте Tailscale.

## 12а. Голос агента

Ещё → Параметры → «Голос агента»: выберите голос (нажатие — прослушать). «Скачать голоса» открывает настройки синтеза речи Google, где можно
загрузить более живые голоса. Если «Ошибка распознавания (11)» повторяется — приложение теперь само пробует ещё раз; если не помогло, обновите
приложение «Google» и проверьте, что включён голосовой ввод Google.

## 13. Фото для агента

В строке команды: **📎** — выбрать фото из галереи, **📷** — сразу сфотографировать камерой телефона. До 4 фото; агент видит их и отвечает по ним.
Из Галереи можно также нажать «Поделиться → RW AI».

## 14. Если приложение вылетело

Вкладка **Журнал** показывает последнюю ошибку (текст сбоя). Перешлите её разработчику — по ней можно найти причину.
